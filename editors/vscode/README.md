# iso-scene для VS Code

Живой предпросмотр `.scene` и `.model` новым движком iso-scene — как в первой
версии расширения, но на Rust-компиляторе.

## Возможности

- **Живое обновление**: предпросмотр пересобирается при наборе (задержка
  настраивается, по умолчанию 150 мс).
- **Три вкладки**: изометрия, чертёж (XY/XZ/YZ на сетке 32 px, как в первой
  версии), воксели (вращение мышью, масштаб колесом, оси X/Y/Z).
- **Статус-бар** `$(eye) Scene` — открыть предпросмотр одним кликом.
- **Языковой сервер** `iso-scene lsp` (запускается сам, без зависимостей):
  ошибки в Problems при наборе — с кодом и точным диапазоном, в том числе
  для `.walls`; подсказка при наведении (объявления, в том числе из
  включённых `.model`, и строки спецификации для ключевых слов);
  переход к объявлению (F12), список символов (Ctrl+Shift+O),
  автодополнение ключевых слов, фигур со сниппетами, объектов после
  `place`, материалов и якорей.
- **Сборка** (`Scene: собрать`) складывает в `out/`: `<имя>.png`,
  `<имя>.vox`, а для `.scene` ещё `<имя>-tiled/scene.tmj`. Лог — в канале
  «Iso Scene».
- **Лист спрайтов** (`Scene: экспорт листа спрайтов`, также в контекстном
  меню редактора): спрашивает число направлений (1/2/4/8/16) и якорь
  (`front`/`center`/…), запускает `iso-scene sprites` и складывает в
  `out/<имя>-sprites/` `<имя>.png`, `.json`, `.tsj`, `.atlas.json` для
  Phaser/PixiJS и `<имя>.debug.png` с рамками клеток и якорями — его
  расширение сразу открывает рядом.
- Если CLI старый и не знает `lsp`, расширение пишет об этом в канал
  «Iso Scene» и работает со встроенными подсказками (`box`, `cyl`,
  `object`, `use`, `merge`, `place`) и ошибками от предпросмотра.

Предпросмотр работает с копией буфера во временной папке и передаёт
`--base <папка файла>`, поэтому файлы проекта не перезаписываются, а
`include` и `material` продолжают работать.

## Установка

```bash
cargo install --path crates/scene-cli
cd editors/vscode && npx @vscode/vsce package
code --install-extension iso-scene-0.4.0.vsix
```

CLI ищется в `PATH`, затем в `~/.cargo/bin/iso-scene`; путь задаётся
настройкой `isoScene.executable`.

## Тесты

```bash
cargo build --release -p scene-cli
node --test editors/vscode/test     # или make vscode-test
```

Тесты проверяют клиент LSP и связку расширения с поддельным модулем
`vscode` на настоящем `iso-scene lsp`; запуск в самом VS Code они не
заменяют.
